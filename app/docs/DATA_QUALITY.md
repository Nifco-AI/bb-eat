# BB-Eat 数据质量报告

本报告对应 `ACCEPTANCE.md` 第 45 行（C7）。所有数字由 `app/src/data/packs/*.json` 直接统计得出，可用
`node app/scripts/data-quality.js` 复现。

**本报告的立场：** 探索目标是 40 种食材 / 20 道食谱。食材 45 条、食谱 20 条，**数量达标**。
但数量达标不等于证据达标——本报告的重点是说明这些条目的证据到底有多薄，以及哪些字段**因为找不到
可溯源依据而被判为"未知"**。`ACCEPTANCE.md` 明确禁止"为了凑数填补缺乏依据的记录"，因此下文的
"未知"计数不是缺陷，而是合规结果。

---

## 1. 条目数量：候选 vs 实际可用

| 类别 | 条数 | 可被推荐/计划 | 仅可浏览 |
|---|---|---|---|
| 真实食材 `ingredients-core` v1 | 45 | 45 | 0 |
| 真实食谱 `recipes-core` v1 | 20 | 20 | 0 |
| 合成演示食材 `demo-synthetic` | 7 | **0** | 仅演示模式 |
| 合成演示食谱 `demo-synthetic` | 6 | **0** | 仅演示模式 |

合成数据在 pack 内带 `is_synthetic: true` 与 `WARNING` 字段，已从所有选择器、计划、记录与回避清单中排除
（见 `regressions.test.ts` 中 D-11 用例）。它存在的唯一目的是在没有真实数据时演示界面，不会污染真实记录。

食谱对食材的全部引用都能解析到真实食材 id，无悬空引用。

## 2. 食物类别覆盖

| food_group | 食材数 | 出现在食谱中 |
|---|---|---|
| grain 谷物 | 6 | 是 |
| vegetable 蔬菜 | 12 | 是 |
| fruit 水果 | 9 | 是 |
| meat 畜禽肉 | 4 | 是 |
| fish 鱼类 | 3 | 是 |
| egg 蛋类 | 2 | 是 |
| legume 豆类 | 3 | 是 |
| dairy 乳制品 | 2 | **否** |
| nut_seed 坚果种子 | 3 | **否** |
| fat 油脂 | 1 | **否** |

10 类中 7 类被食谱覆盖。dairy / nut_seed / fat 只作为食材存在，没有对应食谱——因为这三类的
婴儿制备方式（整粒坚果需磨粉、油脂用量、乳制品月龄门槛）正是最需要医学依据的部分，而我们没有拿到
可溯源的依据，所以**没有编造食谱**。

食谱质地分布：puree 15、mashed 4、minced 1。缺少手指食物（finger food）级别——同样是证据原因，见 §4。

## 3. 月龄证据覆盖：这是本数据包最大的缺口

| 指标 | 结果 |
|---|---|
| 食材带有可溯源的 `min_age_months` | **0 / 45** |
| 食材 `age_status` | 全部 `general_principle_only` |
| 食谱带有可溯源的 `min_age_months` | **0 / 20** |
| 食谱 `age_status` | 全部 `unknown` |

**没有任何一条食材或食谱携带月龄门槛。** 所有 45 条 `min_age_months` 均为 `null`。

原因：WHO 2023 补充喂养指南的全文、以及中国营养学会《7–24 月龄婴幼儿喂养指南》的条文，
在本轮都没有以可引用、可校验的形式取到（见 §6 阻断清单）。能取到的只有"6 月龄开始添加辅食"
这一条通用原则，它**不足以**推导出"西兰花几月龄可吃""三文鱼几月龄可吃"这种逐条门槛。

因此应用的行为是**失败关闭**的：
- 月龄未知 → 不等于"允许"，也不等于"禁止"，界面显式显示"未核验"；
- 应用**不会**基于月龄给出个性化的可吃/不可吃判断；
- `estimateEnergy()` 在任何输入下都拒绝给出数值。

这是本应用在营养建议维度上的真实能力上限，不应被读作"已通过审核"。

## 4. 噎食风险与过敏原覆盖

| 指标 | 结果 |
|---|---|
| `choking_risk = unknown` | **40 / 45** |
| `choking_risk = high` | 5 / 45 |
| `common_allergen = true` | 12 / 45 |

标为高噎食风险的 5 条：胡萝卜（生）、葡萄、葡萄干、花生、核桃。
这 5 条之所以敢标 `high`，是因为它们属于各国指南反复点名的少数几种**形状性**风险食物，
且该结论只往**更保守**的方向生效（标 high 只会增加警示，不会解除任何限制）。

其余 40 条标 `unknown`，并在 `choking_note` 中逐条写明：
"本应用没有找到针对该食材、可溯源的噎食风险分级，因此标记为未核验。"

12 条常见过敏原（小麦面条、鳕鱼、三文鱼、虾、鸡蛋、蛋黄、奶酪、无糖酸奶、豆腐、花生、核桃、芝麻酱）
只用于**提示**，不用于自动回避；是否回避由家长在回避清单中自行决定。

## 5. 官方来源 / 非官方来源比例

来源登记表 `sources.json` 共 12 条。按条目实际引用统计：

| 来源 | 食材条数 | 食谱条数 | 是否官方机构 |
|---|---|---|---|
| `sg_healthhub_weaning`（HPB/HealthHub + KKH） | 5 | 0 | 官方 |
| `bbeat_editorial`（本应用自撰） | 40 | 20 | **非官方** |

**官方来源占比：食材 5/45 = 11%，食谱 0/20 = 0%。**

这个比例很低，必须直说原因：官方来源不是找不到，而是**找到了但不能复制**。
HealthHub 与中国营养学会的内容均为"保留所有权利"，不允许抓取或转载（见 §6）。
因此 `bbeat_editorial` 条目是**我们自己撰写的制备描述**（怎么洗、怎么煮、煮多久、什么质地），
刻意只包含烹饪事实，不包含任何健康主张、月龄门槛或营养声称。这正是为什么 §3 的月龄覆盖是 0。

全部 65 条（45+20）的 `review_status` 均为 `transcribed`，**没有任何一条是 `expert_reviewed`**。
本轮没有医学专业人士参与审核，应用中不存在声称已通过医学审核的内容。

## 6. 不可推荐条数与原因 / 版权与许可阻断

| 来源 | 阻断类型 | 影响 |
|---|---|---|
| 中国营养学会 `cn_cns_iycf_2022` | 版权：版权所有，无开放许可 | 无法转载逐条月龄与份量建议 → §3 覆盖为 0 |
| 中国国家卫健委 `cn_nhc_blocked` | 技术：`nhc.gov.cn` 返回 HTTP 412（WAF 拦截） | 权威中文指南原文完全未取到 |
| HealthHub `sg_healthhub_weaning` / `_allergy` | 版权：使用条款 §12 保留所有权利，禁止抓取转载 | 仅记录来源与极少量非表达性事实，不转载正文 |
| 中国食物成分表 `cn_food_composition_tables` | 介质：纸质出版物，无开放数据集或 API | 无中国本地营养成分数据 |
| WHO 2023 补充喂养指南全文 | 技术：全文未能以可校验形式取得 | 无法推导逐条月龄门槛 |

不可推荐条目数：**0**。原因是我们没有把拿不到依据的条目硬塞进来再标为"不可推荐"，
而是**从一开始就不写入月龄字段**。缺口体现在 §3 的 0/45 与 0/20，而不是体现在条数上。

许可可用的来源：
- `usda_fdc`（USDA FoodData Central）CC0 1.0 / 公有领域，可自由使用；
- `who_growth_standards_2006` WHO 使用条款，非商业用途可复制并注明出处与 URL，**商用需事先书面授权**；
- `who_cf_guideline_2023` CC BY-NC-SA 3.0 IGO；
- `who_anthro_algorithm` GPL-3.0，本应用仅将其作为算法规格参考，**未复制任何 WHO 代码**。

> **遗留给使用方的法律判断：** WHO 生长标准为非商业许可。若本应用将来商业化发行，
> 需要向 WHO 申请书面授权。这不是工程问题，本轮不代为决定。

## 7. WHO 官方计算核对情况

这是本数据包唯一证据完整的部分。

| 核对项 | 结果 |
|---|---|
| WHO xlsx 原始文件 SHA-256 | 与 `cdn.who.int` 逐字节一致 |
| 每文件 L/M/S 行数 | 1158 行全部一致，最大偏差 `0.0e+00` |
| 逆 LMS 反推 vs WHO 自带 SD 列 | 最坏情况 `0.000500`，超过 `0.001` 的值为 **0 个** |
| ±3SD 尾部调整 | 正确地只对 `weight_for_age` 生效 |
| 超出已发布天数范围 | 边界检查后**拒绝给出 z 分**，容差 1 天 |

以上五项由独立 Verifier **重新下载原始文件、重新实现算法**后复核得出，不是基于本实现的自我声明。
正态分布 CDF 使用 Abramowitz & Stegun 7.1.26 近似（已在 `growthRef.ts` 注释中更正说明，非精确值）。

## 8. 结论

| 维度 | 状态 |
|---|---|
| 条目数量（40/20 目标） | **达标** 45/20 |
| 食物类别覆盖 | 部分：10 类中 7 类有食谱 |
| 制备方法描述 | 完整，自撰，仅烹饪事实 |
| 月龄证据 | **0 覆盖，最大缺口** |
| 噎食分级 | 89% 未核验 |
| 官方来源占比 | 食材 11%，食谱 0% |
| 医学审核 | **无，且未伪称有** |
| WHO 生长标准计算 | **已独立复核通过** |

一句话总结：**生长曲线这一层的科学性是可信且被独立复核过的；营养与月龄建议这一层则没有足够依据，
应用因此在该层主动拒绝给出个性化建议。** 本地记录、库存、回避清单、备份等不依赖医学依据的功能
不受此限制，均为真实可用功能。
